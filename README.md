# Unovi OS
Unovi OS is an unfinished Open Source Operating System mainly made in C. It is 64 Bit OS and uses a Limine UEFI loader
It needs work and edits so feel free to download it and make edits to it and this is a project that anyone can explore, learn from, modify, and improve.
Show off your projects, modifications, and experiments using #UnoviOS so others can discover your work.

Thanks for helping.

This will help make improvements for helping improve Unovi OS. Every contribution helps make the project better for everyone!
